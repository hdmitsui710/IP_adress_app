1

ネットでは「番号」が住所。「名前」は呼び名

コンピュータ同士が通信するとき、相手を見つける手がかりになるのは IPアドレス(番号)です。でも「203.0.113.10」のような数字は、人間には覚えにくいですよね。

そこで人間向けに、文字でできたドメイン名(名前)がつけられています。スマホの連絡先アプリで「田中さん」と選ぶだけで電話がかけられるのと、同じ考え方です。

ドメイン名・ホスト名(名前)

文字でできていて、人間が読みやすく覚えやすい。
www.example.jp のような形です。

IPアドレス(番号)

ネットワークにつながった機器の番号。0〜255の数字を4つ、「.」でつないだ形です。コンピュータ同士は、この番号で通信します。

ひとこと：最近は、もっと長い「IPv6」という番号も使われています。この教材では、4つの数字でできた「IPv4」で説明します。

2

ホスト名・ドメイン名・IPアドレスの関係

人の名前にたとえると、ホスト名が「下の名前」、ドメイン名が「名字」です。同じ名字(ドメイン)の中で、下の名前(ホスト名)を使って、だれのことかを区別します。

下の一覧から名前を選ぶと、名前がどう分かれるか、そしてどのIPアドレスに対応するかが表示されます。

ホスト名
ネットワークにつながった1台1台のコンピュータにつける名前。www は Webサーバ、mail はメールサーバ、のように役割を表すことが多い。
ドメイン名
コンピュータたちが所属するグループの名前。example は組織や会社の名前、jp は「TLD(トップレベルドメイン)」といって、国や種類を表す(jp=日本、com=企業など)。
FQDN
ホスト名とドメイン名をつなげた、世界で1つに決まる名前のこと(完全修飾ドメイン名)。www.example.jp がその例。

DNSサーバがもっている「対応表」のイメージ(行を押すと選べます)

  • 同じドメイン(example.jp)の中でも、ホスト名がちがえば別のコンピュータ。だからIPアドレスもちがいます。
  • ホスト名が同じ www でも、ドメインがちがえば別のものです。www.example.jp と www.example.com は別のコンピュータです。
  • 読む順番に注意。住所は「日本 → 東京都 → ○○区」と大きい方から書きますが、名前は逆で、小さい方(ホスト名)から書きます。

DNSサーバの働き:名前から番号を調べる案内係

DNSサーバは、ドメイン名に対応するIPアドレスを調べて教えてくれる、ネットワークの「案内係」です。DNS は Domain Name System(ドメイン・ネーム・システム)の略です。

    DNSサーバは、ネットワークのどこにいる?

    DNSサーバも、ネットワークにつながったふつうのコンピュータ(サーバ)です。IPアドレスをもっていて、名前を聞かれると答えを返します。ただし1台だけではなく、いろいろな場所に役割を分けて置かれています。

    下のボタンで、DNSサーバがいる場所を光らせてみましょう。図の機器を押すと、説明も出ます。

    図は横にスクロールできます。

    図の機器を押してみよう

    PC、ルータ、DNSサーバなど、押すと役割の説明が表示されます。

    身近な場所にいる:キャッシュDNSサーバ

    PCが最初に聞く相手です。プロバイダや学校の中に置かれています。家のルータが取り次いで、実際にはプロバイダのDNSサーバが答えることも多いです。

    インターネットの中にいる:ルート・TLD・権威DNSサーバ

    名前の階層(. → jp → example.jp)ごとに担当が分かれています。答えを知らないキャッシュDNSサーバが、上から順にたどって聞きにいきます。

    PCの設定に書いてある:DNSサーバのIPアドレス

    PCには、聞く相手のDNSサーバのIPアドレスが設定されています。名前で書くと、その名前を調べるためにまたDNSが必要になってしまうので、数字で書いておきます。ふつうはネットにつなぐと自動で設定されます。

    やってみよう:自分のPCが使っているDNSサーバを調べる

    ターミナル(Windowsは「コマンドプロンプト」)で、次のコマンドを実行してみます。自分の学校のWebサイトの名前で試すと、本物のIPアドレスが出てきます。

    nslookup 調べたい名前

    結果の最初に出る「Server(サーバー)」と「Address(アドレス)」が、あなたのPCが使っているDNSサーバです。Windowsなら ipconfig /all の「DNS サーバー」でも確認できます。
    学校の端末では使えないことがあります。先生の指示にしたがってください。

    5

    まとめとクイズ

    • IPアドレスは、ネット上の住所(番号)。ドメイン名は、人間が覚えやすい名前。
    • ホスト名(1台のコンピュータの名前)+ ドメイン名(グループの名前)で、世界で1つの名前(FQDN)になる。
    • DNSサーバは、名前に対応するIPアドレスを教えてくれる案内係。身近なDNSサーバから、インターネット上のDNSサーバまで、役割を分けて置かれている。
    DNS
    名前とIPアドレスを結びつけるしくみ(Domain Name System)。
    DNSサーバ
    名前の問い合わせに答えるコンピュータ。
    キャッシュDNSサーバ
    PCが最初に聞く相手。調べた答えを一時的に覚えておく。
    権威DNSサーバ
    ドメインの対応表を実際にもっている、正式な答えの出どころ。
    ドメイン名
    ホスト名の右側にある、グループの名前(例:example.jp)。
    ホスト名
    1台のコンピュータにつける名前(例:www)。
    IPアドレス
    機器の番号。0〜255の数字を4つ「.」でつなぐ(IPv4)。
    キャッシュ
    いちど調べた答えを、しばらく覚えておくこと。

    理解チェック

    この教材で使っているドメイン名とIPアドレスは、説明用に作った架空のものです。実際のインターネットのようすとは少しちがいます。
